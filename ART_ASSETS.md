# Art assets for the desktop/tools release

## Blue desktop wallpaper

Project path: `assets/desktop/wallpaper_blue.png`.

Created with the built-in image-generation tool, then copied into this project. It is an original wallpaper; it is not Microsoft's shipped wallpaper. Other desktop icons, the dusk variant and all retail print artwork are authored by the included Python build scripts. The build script preserves the generated blue wallpaper when it exists.

Generation prompt:

> Use case: stylized-concept. Asset type: original widescreen desktop wallpaper for the in-game computers of a PC repair simulator. Generate only the wallpaper, no monitor, no UI, no icons, no words or logos. A refined contemporary OS background: flowing broad satin-blue folded ribbons with soft luminous edges and smooth sculptural curves, concentrated in the right two-thirds. Deep navy to royal blue gradient background, quiet dark negative space at left for desktop icons. Soft studio lighting, polished clean 3D render, gentle cyan highlights, restrained contrast. Original composition inspired by modern Windows 11 desktop aesthetics but do not reproduce the Microsoft Bloom wallpaper. Landscape 16:10, 1280x800 or a similar landscape aspect. No grain, no grid, no hard polygonal lines, no watermark.
