# Repaired archive

The release 20 file available for download was truncated at 61,562,231 bytes and lacked the ZIP central directory and end record. This was an invalid archive, not an extraction-setting problem.

Recovery used the complete development checkpoint and 439 intact entries from the damaged file, checking each recovered entry's length and CRC. The missing city-update source was reapplied. The resulting package retains the 192 × 152 m district, eight traffic cars, four animated cyclists, additional pedestrians, detailed CC0 human heads, revised vehicles and building surfaces, native 1080p, NVMe/assembly features, combined delivery cartons, removed menu photograph and stable workshop shadows.

Validation of this rebuilt release is in verification_repacked: 24 rendered checks, successful assembly rule/economy suites, and a 100-frame static workshop test with zero sampled pixel change. Tests run under Panda3D 1.10.16 and software OpenGL, not the user's Windows GPU.

The ZIP uses ordinary Deflate compression, has no encryption or split volumes, and is checked with both Python zipfile and the independent unzip program. All extracted files are compared against the packed source using SHA-256. The uploaded replacement is downloaded again for byte-for-byte verification before delivery.

Historical verification images are omitted from this distribution; game assets, source, checks, documentation and the current verification report are included.
