# Art assets for the desktop/tools release

## Current desktop artwork (release 24)

`assets/desktop/wallpaper_blue.png` and `wallpaper_dusk.png` are original geometric gradients and line compositions. Nine matching application icons are drawn from original geometric shapes. Rebuild them using `tools/build_interface_art.py` with Pillow. This replaces the older generated ribbon wallpaper and its derived dusk variant; the former prompt is historical and does not describe the current files.

## Product photographs added in this update

Actual retailer/manufacturer product photographs are included under assets/products. Per-image original URLs, seller attribution, listing URLs and SKUs are recorded in assets/retail_catalog.json and PRICE_REFERENCE.md. ## Graphical makeover

Nine original 1024px procedural surface textures are generated by tools/build_visual_materials.py. That development tool uses NumPy and Pillow; the game itself adds no runtime dependency. Geometry in pcshop/art_direction.py and the revised case frame is authored directly in code. assets/menu_workshop.jpg is a capture of the running game. Framed product photographs reuse the existing attributed catalog images; no new third-party photographs are introduced. Shared material responses use Panda3D's built-in lighting.

## Release 24 resident redesign

The existing CC0 MakeHuman-derived head mesh listed below remains the base. New code applies skull, jaw and nose variation, hairstyle clipping and additional bob, ponytail and curl geometry. Twelve profile definitions control wardrobe, body shape and coloring. Garments, articulated hands, footwear, gait and distant models are original procedural game geometry. The head license in `assets/people/LICENSE.txt` is unchanged.

Release 25 retains the same credited CC0 head source. The continuous neck extension, face morphs, revised scalp, eyelid rig, cloth-normal corrections, unlettered RAM geometry and desktop layout are game-authored changes. No new third-party art was added.
